# /research — 목적지부터 찾는다

> `/research <자연어>` 가 기본이다. 첫 낱말이 **`domains/` 아래 폴더 이름**이면 그 도메인 맥락으로 간다
> (`/research study 편입 정원이 줄었나?`).

## 경계 — 먼저 어느 스킬인지 정한다

| 물음의 모양 | 부를 것 |
|---|---|
| **목적지가 정해져 있다.** 「그 페이지에 뭐라고 적혀 있나」 | **`/errand`** |
| **목적지를 «찾는 것»부터가 일이다.** 「이게 사실인가」·「누가 제일 나은가」·「그런 일이 있었나」 | **`/research`** ← 여기 |
| 도메인 전부를 정기적으로 훑는다 | **`/sweep`** |

들어가서 봐야 할 페이지가 정해지는 순간 **`/errand` 를 부른다** — 지도·`access`·포트·후퇴 신호를 저쪽이 안다.

---

## 🔴 등급 — 모든 결론에 이게 하나씩 붙는다

**조사의 실패는 「못 찾았다」로 오지 않는다. 「찾았는데 틀렸다」로 온다.** 못 찾으면 빈 칸이 남아 눈에 띈다.
그런데 실제로 일어나는 건 **요약이 빈 데 없이 채워져 돌아오는 것**이고, 그건 「다 읽었다」로 착각된다.
그래서 이 스킬이 재는 건 **«얼마나 찾았나»가 아니라 «무슨 등급으로 알았나»** 다.

| 등급 | 뜻 | 이걸 붙일 수 있는 조건 |
|---|---|---|
| **직접 봄** | 크롬으로 그 화면을 떴다 | `/errand` 로 실제 DOM·본문을 봤다. **되돌릴 수 없는 절차·정원·마감은 이것만 인정된다** |
| **원문 봄** | 1차 출처 원문을 받았다 | 공식 API·RSS·공시 원문·PDF 본문. 모델 요약을 거치지 않았다 |
| **요약만 봄** | `WebSearch`·`WebFetch` 를 거쳤다 | 🔴 **「요약만 봄」이라고 적는다.** 값은 맞을 수 있어도 **제약 문장이 빠져 있다**. 「읽었다」는 원문을 받은 뒤에 쓴다 |
| **확인 못 함** | 못 얻었다 | **왜 못 얻었는지**를 같이 적는다. 빈 칸이 틀린 값보다 싸다 |

- **한 줄에 등급 하나만 붙인다.** 「예전에 적어둔 것」과 「지금 가서 봤다」는 줄을 나눠 적는다.

## 도구 사다리 — 싼 데서 시작하되, 비싼 쪽으로 «올라갈 줄» 알아야 한다

| 순위 | 도구 | 값 | 🔴 조용한 실패 모드 |
|---|---|---|---|
| 1 | 도메인 폴더(`notes.md`) · 지난 조사(`research/`) | 공짜 | **낡았다.** 언제 적힌 줄인지 안 보면 어제 값을 오늘 값으로 쓴다 |
| 2 | 공식 API · RSS · 피드 | 매우 쌈 | 있는데 안 보인다 |
| 3 | `WebSearch` | 쌈 | 검색어에 없는 건 **영영 안 보인다** |
| 4 | `WebFetch` | 쌈 | 🔴 **못 읽었다고 말하지 않는다. «그럴듯한 틀린 것»을 돌려준다** |
| 5 | 크롬 (`/errand`) | 비쌈 | 느리다. 그래도 **이것만이 「직접 봄」이다** |

- **3·4 에서는 «어디를 봐야 하는지»를 얻는다.** 정찰이다 — 결론은 1·2·5 에서 받은 원문으로 세운다.
- 반대 방향도 실패다 — RSS 가 열려 있는데 크롬으로 홈페이지를 파싱해 피드보다 적게 얻은 적이 있다.
  **«직접 봄»은 되돌릴 수 없는 것·마감·정원에서만 의무다.**

## 0. 먼저 읽는다

1. **이미 판 것** — `research/` 아래 지난 보고서를 낱말로 찾는다(`grep -ril <낱말> research/`).
   있으면 그 하위 물음은 재사용하고, 답에 「(재사용 · N일 전 원문 봄)」을 붙인다. **마감·접수·정원은 그날 다시 본다.**
2. **[`LESSONS.md`](../../../LESSONS.md) §리서치** — 조사가 «조용히 틀리는» 법. 처음부터 끝까지.
3. **도메인을 지목받았으면** `domains/<이름>/DOMAIN.md` 의 `하지 말 것` 이 **최우선 제약**이다.

## 1. 물음을 쪼갠다 — 판정 기준을 먼저 적는다

큰 물음 하나를 **하위 물음 3~6개**로 쪼개고, 각각에 **«무엇을 보면 답인가»(판정 기준)** 를 먼저 적는다.
기준이 먼저 서 있어야 「그럴듯한 걸 봤을 때」가 아니라 **「기준을 봤을 때」 멈춘다.**

| 하위 물음 | 무엇을 보면 답인가 | 어디서 | 등급 목표 |
|---|---|---|---|
| 예) 증설을 발표했나 | 회사 공식 보도자료·공시에 그 문구가 있나 | 보도자료 목록 전수 + 공시 | 원문 봄 |

- 하위 물음에 넣는 고유명사·번호·날짜·제품 목록이 **기억이면 `(미확인)`** 을 붙인다 — 원문이 반박할 자리다.
- **부재를 물었으면**(「~했나」·「그런 거 있나」) 무엇을 전부 봤는지(**모수**)를 정하고 전수로 본다.
- 쪼갠 목록과 **가정 줄 두 개**(«무엇이 약해서» · «무엇을 바꾸려고», 그리고 «어느 나라·어느 시장 기준»)를
  사용자에게 한 번 보여주고 **곧바로 진행한다** — 틀렸으면 사람이 그 줄에서 고친다.

## 2. 정찰 — 싼 것부터. 여기서 얻는 건 «어디를 볼지»다

- `WebSearch` 는 검색어를 **그 바닥의 말·반대말·연도**로 바꿔가며 여러 번 친다.
  상업 질의(「비교·best」·「배우는 법」)는 1페이지를 SEO 가 덮는다 — 곧장 1차 출처(공식 문서·개발자 블로그·Ask HN)로 간다.
- `WebFetch` 로 받은 건 **받은 자리에서 «요약만 봄»으로 표시**한다.
- **싼 원문 길**을 먼저 쓴다: `<url>.md`·`llms.txt` · 논문 `arxiv.org/html/` · 코드 `raw.githubusercontent.com` ·
  공시 API · 사라진 페이지는 archive.org 스냅샷. `WebFetch` 가 PDF 를 «못 읽는다»하면 저장된 파일을 파이썬으로 연다.
- **하위 물음이 3개 넘고 서로 독립이면 `Agent` 로 병렬**로 돌린다. 자식은 이 파일을 안 읽고 뜨니,
  자식 프롬프트에 **최소 이 여섯**을 넣는다:
  1. 위 **등급표 전문**(원문 그대로)
  2. 그 하위 물음의 **판정 기준**
  3. **조회만 한다** — 신청·제출·결제·전송·삭제에 닿으면 멈추고 보고한다
  4. 돌려줄 형식 = `찾은 것` / `등급` / `출처 URL` / `확인 못 함` / **크롬으로 꼭 봐야 할 곳 3개**
  5. «원문 봄» 줄마다 **받은 파일 경로:줄 + 원문 문장 그대로**(번역·요약 금지) — 부모가 §5-b 로 grep 한다
  6. 크롬이 없는 자식의 **최고 등급은 「원문 봄」** · 요청 헤더에 사용자 이메일·실명을 싣지 않는다
- 자식 보고는 **받는 즉시** 파일로 옮겨 적는다(맥락이 압축되면 사라진다).

## 3. 올라간다 — 결론이 걸린 것만 크롬으로

```
/errand <그 페이지에서 확인할 한 가지>
```

**넷 중 하나라도 걸리면 올라간다:**

| 조건 | 왜 |
|---|---|
| 되돌릴 수 없는 절차 (신청·상담·제출·결제) | 요약이 **금지·1회 한정·미첨부 시 취소**를 버린다 |
| **마감·정원·예약**이 답에 든다 | 목록과 상세가 다르다 (`~08.18` vs `08.18 09:00`) |
| 결론이 「오늘/내일 뭘 해야 한다」 | 15시간을 잃을 뻔한 실측이 있다 |
| `WebFetch` 결과가 **두 번 이상 앞뒤가 안 맞았다** | 못 읽었다고 말하는 대신 지어낸다 |

- 403 이면 셋으로 가른다 — **도구 차단**(→ 크롬 한 번) / **로그인 벽**(→ 그날 접는다) / **약관 금지**(→ 「약관상 불가」).
- `/errand` 에는 **한 번에 한 가지**를 시킨다.
- 「0건」은 이 순서로 가른다 — 검색 전후 총 N건 비교(안 줄면 검색이 안 먹었다) → 도착 주소 → 소프트 404 → 로그인 창 문구.

## 4. 대조·반증 — 결론을 세우기 전에 한 번

- **같은 값을 두 곳에서 본다.** 안 맞으면 **둘 다 적고 왜 다른지를 묻는다.** (기준일·집계 기준·판 연도가 다른 경우가 많다)
- **반증을 한 번 친다.** 「A 다」면 「A 가 아니라는 증거」를 찾아본다 — 그걸 거쳐야 확증만 모은 게 아니게 된다.
- 요약에 **금지·조건·예외 문장이 하나도 없으면** «제약이 버려진 요약»으로 보고 원문을 연다.
- **출처의 신선도를 잰다** — 날짜 없는 출처는 등급을 한 칸 내린다. 별 수·상단 노출은 신선도가 아니다.

## 5. 답한다 — 모든 줄에 등급을 붙인다

```
답: <물어본 것의 값>                        ← 첫 줄
근거: <URL> · <언제 봤나> · [직접 봄|원문 봄|요약만 봄]
확인 못 함: <무엇을·왜>                      ← 있으면 반드시. 없으면 「없음」
가정: <범위를 이렇게 잡았다>
```

**「확인 못 함」은 위쪽(답·근거 바로 밑)에 둔다** — 글이 잘리면 아래부터 사라진다.

말투·기호·배치와 그림 인용은 [`CLAUDE.md`](../../../CLAUDE.md) §사람이 읽는 결과물 쓰는 법을 따른다. 남에게 줄 보고서는 공식 문어체·검정 단색·그림마다 출처·참고문헌으로, 내보내기 직전 검사 한 줄을 돌린다.
자식에게도 «본 사진·그래프·표는 받을 수 있으면 전부 받아 작업 루트 `figures/` 에, 한 장 = 한 줄로 출처·접속일·써도 되나»를 시킨다.

### 5-b. 🔴 인용문 실재 검사 — 답을 내기 «전에» 한 번

«원문 봄»·«직접 봄» 줄은 **받아 둔 파일에 그 문장이 정말 있어야** 그 등급이다. 자식이든 나든 요약이 끼면 «그럴듯한 인용»이 생긴다.

1. 그 줄마다 근거를 이 꼴로 붙인다: `근거: <파일>:<줄> · "<원문 문장 그대로>"` — **원문 언어 그대로**(영어면 영어). 번역·요약·말 다듬기를 하면 아래 검사에 안 걸린다.
2. 답을 내기 전에 그 줄마다 `grep -F "<인용 중 20~40자>" <파일>` 을 돌린다. HTML 은 태그가 끼어 안 걸리니 텍스트로 뽑아 둔 파일에 돌린다. 크롬으로 본 화면은 `text` 결과를 파일로 저장해 같은 검사를 한다.
3. **0건이면 그 줄을 «요약만 봄»으로 내리거나 원문을 다시 연다.** 「거의 같은 말이 있다」는 통과가 아니다.

결론이 걸린 줄(답·판정·숫자)은 전부, 나머지는 표본 몇 개만 해도 된다. 등급표가 «어디서 왔나»를 재면 이 검사는 «정말 거기 있나»를 잰다.

## 6. 🔴 되먹인다 — 같은 턴에

다음 세션은 오늘 밟은 걸 모른다. 이 단계가 이 스킬을 «검색»이 아니라 «쌓이는 조사»로 만든다.

**① 조사 자체를 남긴다** — `research/YYYY-MM-DD-<슬러그>/REPORT.md` 에 답·근거·등급·확인 못 함을 그대로.
원자료(PDF·CSV)가 있으면 같은 폴더 `raw/` 에. (`research/` 는 `.gitignore` 다 — 커밋 안 된다)

**② 새로 알아낸 것을 제자리에:**

| 새로 알아낸 것 | 어디에 |
|---|---|
| **조사가 조용히 틀린 방식** (도구가 지어냈다·등급 판단·먹힌 검색어) | **[`LESSONS.md`](../../../LESSONS.md) §리서치** 에 날짜로 시작하는 항목 하나 |
| 사이트 구조·셀렉터·로그인 | `LESSONS.md` §브라우저 |
| 새 목적지·`access`·`prefer` | `module_browser/site_map.json` |
| 도메인 조사였으면 결과 | `domains/<도메인>/notes.md` 한 줄 (`YYYY-MM-DD`) |

- **새로 알아낸 것만 적는다.** 이미 있는 교훈의 재확인이면 그 항목 제목 끝에 `(또: 날짜)` 만 더한다.
- **판정법은 할 일로 쓴다** — 「X 하지 마라」 대신 «그 함정을 안 밟는 행동»을.
- **뭘 적었는지 사용자에게 한 줄로** 보여준다.

## 지키는 선

- **조회만 한다.** 신청·제출·결제·전송·삭제에 닿으면 멈추고 물어본다.
- **캡차·429·로그인 벽은 후퇴 신호로 받는다** → `/errand` §후퇴 신호.
- **목록이 필요하면 공식 API 로 받는다.** 대량 스크래핑은 대부분 약관 위반이다.
- 남의 단체·개인 자료를 저장하기 전에 **전화번호·이메일을 한 번 훑어** 빼고 저장한다.
- 커밋되는 파일(`LESSONS.md`·`site_map.json`)엔 **방법과 수치만** 적는다.
