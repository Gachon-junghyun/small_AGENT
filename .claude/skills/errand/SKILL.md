# /errand — 시키면 간다

> `/errand <자연어>` 가 기본이다. 첫 낱말이 **`domains/` 아래 폴더 이름**이면 그 도메인 맥락으로 간다.
>
> | 입력 | 뭐가 달라지나 |
> |---|---|
> | `/errand 교보문고 광화문점 몇 시까지 해?` | 그냥 심부름 |
> | `/errand study 이번 주 과제 마감 언제야?` | `domains/study/DOMAIN.md`·`notes.md` 를 먼저 읽고, 끝나고 `notes.md` 에 남긴다 |
>
> 경로는 리포 루트(= 세션 cwd) 기준 상대경로로 쓴다. 절대경로는 PC 마다 다르다.

> 🔴 **목적지를 «찾는 것»부터가 일이면 이 스킬이 아니라 [`/research`](../research/SKILL.md) 다.**
> 「이게 사실인가」·「그런 일이 있었나」·「누가 제일 나은가」류. 저쪽이 물음을 쪼개고 **여기를 부른다** —
> 이 스킬은 **목적지가 정해졌을 때** 제일 세다.

**이 스킬은 모든 사이트·도메인에 하나뿐이다.** 사이트마다 심부름 스킬·파서를 만들지 마라 —
반복되는 절차는 `site_map.json` 의 `recipes`(데이터)로 뺀다.

## 태도 (이게 이 스킬의 존재 이유다)

- **되묻지 말고 간다.** 지점·기간·범위가 모호하면 제일 그럴듯한 걸로 잡고 가서, 답과 함께
  "이걸로 잡았다"를 한 줄 붙여라. 라운드트립이 비싸다.
- **답이 먼저, 과정은 뒤.** 첫 줄에 사용자가 물어본 값. 어떻게 찾았는지는 그다음.
- **막히면 우회하지 뚫지 마라.** 아래 §후퇴 신호.
- **모르면 모른다고 한다.** 확인 못 한 값을 그럴듯하게 채우지 마라. **추정한 부분은 `(추정)`** 으로 표시한다.

## 🔴 판정·중요한 값은 «캡처»하고 «검증에 검증»을 한다

> 실제 사고: 10행씩 쪽이 나뉜 잔고표의 **1쪽만 읽고**, 그 숫자로 남에게 불이익을 매겼다.
> 표 바로 밑에 쪽 번호 「1 2 3」이 있었는데 칸 이름만 보고 넘어갔다. 같은 날 저장한 체결내역과 한 번만 맞춰 봤어도 잡혔다.

**어디에 걸리나** — 값이 아래 중 하나에 쓰이면 전부:
- **판정**: 순위·합불·자격·위반 여부 — 누군가에게 이익이나 불이익이 가는 것
- **남에게 전달**: 공지·보고·게시 — 사람이 그 숫자를 믿고 남에게 말하는 것
- **돈·마감·되돌릴 수 없는 결정**의 근거가 되는 값

**다섯 개 다 통과해야 «확정»이다:**
1. **캡처한다.** 값이 나온 화면을 `shot --full` 로 **전부** 찍는다 — 쪽이 나뉘면 쪽마다. 찍은 걸 **`Read` 로 열어 행 하나하나 대조**한다. 찍기만 하고 안 보면 안 찍은 것과 같다.
2. **「다 왔나」를 본다.** 쪽 번호·「더보기」·스크롤·「총 N건」. 🔴 **행 수가 딱 떨어지면(10·20·50·100) 잘렸다고 의심하라.**
3. **독립된 두 번째 출처로 맞춰 본다.** 잔고면 «어제 잔고 + 오늘 체결», 합계면 «개별 합». 안 맞으면 확정하지 마라. 두 번째 출처가 없으면 **「교차검증 못 함」** 이라고 적는다.
4. **말이 되나 본다.** 숫자가 상황과 맞는지 한 번 따져라. **그럴듯해 보이는 게 제일 위험하다.**
5. **판정 전에 한 번 더.** 화면은 그새 바뀐다.

- 1~5 를 다 못 했으면 값 옆에 **`(검증 전)`** 을 붙이고, 판정·게시·공지에 쓰지 마라.
- **숫자만 된 것 말고 형식도 의심하라** — 종목코드처럼 영문이 섞이는 값을 `\d{6}` 같은 필터가 조용히 버린다.

## 0. 도메인을 지목했으면 맥락부터

`domains/<이름>/DOMAIN.md` 와 `notes.md` 를 읽고 **세 가지만** 뽑아 심부름에 반영한다:

| `DOMAIN.md` 칸 | 심부름에 어떻게 쓰나 |
|---|---|
| **하지 말 것** | **최우선 제약.** 여기에 걸리면 그 심부름은 거기서 멈추고 사람에게 올린다 |
| 알아둘 것 | 사람 이름·용어·지난 결정. 검색어와 판단의 재료 |
| 이게 뭔데 | 왜 챙기는 일인지 — 답의 초점을 여기 맞춘다 |

`notes.md` 는 **이미 아는 것**이다. 다시 조사하지 말고 바뀌었는지만 확인한다.

## 1. 목적지를 지도에서 찾는다 — 사이트를 뒤지기 전에 지도부터

```powershell
python -m module_browser find 서점 영업시간     # 어디로 가야 하나
python -m module_browser go kyobobook 통합검색  # 목적지 URL
python -m module_browser map session            # 1회 로그인해두면 되는 곳들
```

**`access` 를 반드시 보라. 이 네 글자가 행동을 정한다:**

| access | 뭘 하나 |
|---|---|
| `open` | 그냥 간다 |
| `session` | 로그인 판정 먼저 (`python -m module_browser check <사이트>`). 로그인이 풀렸으면 사람을 부르고 멈춘다 |
| `api` · `prefer` 필드 | **브라우저 쓰지 마라.** 더 싸고 안 깨지는 경로가 이미 적혀 있다 |
| `blocked` | **하지 마라.** `why` 를 사용자에게 그대로 전하고 끝낸다 |

**지도 항목에 `recipes` 가 있으면 스텝을 새로 짜지 마라** — `python -m module_browser fast recipe <사이트> <이름>`
한 줄이 크롬 기동·로그인 벽 감지·표 긁기까지 한다(예: `fast recipe hacker_news 프론트`).
**같은 심부름을 두 번째 하게 되면 그때 레시피로 빼라** — 스텝은 `site_map.json` 에 적는 데이터고 코드는 안 는다.

지도에 없는 사이트면 그냥 가되, 끝나고 **§기록** 을 하라.

## 2. 브라우저로 간다 — **파이썬 스크립트를 쓰지 마라. `fast` 로 한 번에 부어라**

```powershell
python -V                                             # ⓪ `Python 3.x.y` 가 아니면 스토어 스텁이다 (LESSONS.md)
python -m module_browser status                       # ① 크롬이 떠 있나. 없으면 `launch`
python -m module_browser fast tabs                    # ② 남의 탭 확인 (11ms)
python -m module_browser fast newtab about:blank      # ③ 내 작업용 새 탭
python -m module_browser fast run - --tab <내탭> < steps.json   # ④ 이동·대기·추출을 한 방에
```

`steps.json` 은 스텝 배열이다. **한 번의 호출로 심부름 한 건이 끝나는 게 목표다:**
```json
[["goto","https://…","document.querySelectorAll('.item').length>=10"],
 ["eval","Array.from(document.querySelectorAll('.item')).map(e=>e.innerText)"],
 ["goto","https://…/detail","document.body.innerText.includes('가격')"],
 ["text"], ["alts"]]
```
스텝: `goto(url, until?)` `until(js)` `eval(js)` `text(css?)` `links(부분문자열)` `alts()`
`click(css)` `shot(path?, full?)` `sleep(초)` · `sleep(lo, hi)`(무작위) · `each(js, [하위 스텝])`.
실패해도 **거기까지 건진 건 돌려준다.**

- **`sleep` 을 박지 마라. `goto` 의 세 번째 인자(`until`)에 "내가 필요한 것"을 써라.**
  실측으로 `sleep(6)×3 = 18초`가 `until` 로 **0.97초**가 됐다. 🔴 `until` 은 **`!!` 로 불리언**을 돌려줘라.
- **여러 값이 필요하면 `eval` 하나에 배열로 받아라.** 요소마다 왕복하면 20개에 140ms, 한 방이면 0.7ms 다.
- **`--tab` 을 항상 줘라.** 안 주면 **첫 탭**이 잡힌다 — 내가 방금 연 탭이 아니다.
  값은 URL·title 의 부분문자열이거나 `newtab` 이 돌려준 `id` 다. 새 탭은 `about:blank` 로 잡고, 첫 `goto` 뒤엔 그 도메인 조각으로 잡아라.
- 🔴 **포트가 곧 «로그인 계정»이다.** 기본은 9222. 다른 계정으로 할 일은 다른 포트(예: 9223)를 쓴다 —
  포트마다 크롬 프로필이 따로다. **`fast` 는 `--port 9223`, `launch`/`status`/`shot`/`close` 는 위치 인자다.**
  ⚠️ 포트를 빠뜨리면 에러 없이 9222 로 간다.
- **프로필은 남의 탭을 들고 있다.** `fast tabs` 로 먼저 훑고, 신청서·결제류가 열려 있으면 그 탭은
  navigate 조차 하지 마라. **새 탭에서만 움직여라.**
- 크롬을 새로 띄워야 하면 **`python -m module_browser launch`** 로 띄워라 — 창 가림 방지 플래그가 붙는다.
  손으로 띄운 크롬엔 그 플래그가 없어서 드롭다운이 안 열린다(LESSONS.md 2026-08-07).
- 셀레늄(`import module_browser as B; B.ensure(9222)`)은 **로그인처럼 입력이 까다로울 때만.**
  `attach()` 가 매번 chromedriver 를 띄워 **1.6초**를 문다. 스크립트를 쓰게 되면 `$env:TEMP` 에 쓰고 돌려라.

**★ 예상과 다르게 굴면 즉시 화면을 찍어라.** 한 번 실패했으면 두 번째로 같은 벽에 부딪히기 전에:
```powershell
python -m module_browser fast shot --tab <내탭>            # → %TEMP%\shots\shot_NNN.png. Read 로 열어봐라
python -m module_browser fast shot x.png --full --tab <내탭> # 스크롤 전체(긴 표)
```

**클릭이 조용히 씹히면 `click` 스텝이 원인을 말해준다** — «가려져 있다 ← 'DIV.dim' 가 덮음» /
«크기가 0인 요소다» / «뷰포트 밖이다». 덮였으면 모달을 닫고, 0크기·화면밖이면 셀렉터가 틀렸다.
**`alert` 는 알아서 닫히고, `confirm`·`prompt` 창은 «취소»로 닫힌 뒤 그 스텝이 `DialogCancelled` 로 실패한다**(결과의 `dialogs` 칸) — 창 문구를 사람에게 보여주고 멈춰라. 진행은 사람이 누른다.
그 밖에 볼 것: 줌이 100%인가 · `alert` 이 떠서 자동 취소됐나 · 창이 뒤에 있나.
**나가기 전에 [`LESSONS.md`](../../../LESSONS.md) §브라우저에 그 증상이 있나 훑어라.**

## 3. 답한다

값 + **기준 시각** + 출처. 시간이 걸린 답이면 남은 시간까지 계산해서 준다.
추정한 건 `(추정)`, 확인 못 한 건 "확인 못 함"으로 남긴다.

## 후퇴 신호 — 이게 뜨면 그 사이트는 그날 그만 두드린다

| 신호 | 대응 |
|---|---|
| **캡차 / 보안확인** (`ElementClickIntercepted` 연발 포함) | **즉시 중단.** 재시도·우회 금지. 공식 사이트나 공식 API 로 갈아타라 |
| 429 / IP 차단 / "rate limit" 안내 페이지 (200 인데 결과가 없다) | 중단하고 사용자에게 보고 |
| 로그인 벽 | `check` → 로그인이 풀렸으면 사람을 부른다. **자동 로그인 재시도 금지** |

> 캡차는 **극복 대상이 아니라 경고**다. 계정 잠기는 게 답 못 찾는 것보다 훨씬 비싸다.
> 같은 사이트를 여러 장 열 땐 처음부터 `["sleep", 3, 9]` 무작위 대기를 끼워라.

## 절대 안 하는 것

- **되돌릴 수 없는 액션 금지.** `site_map.json` 의 `can` 이 그 표시다 — 신청·제출·지원·주문·결제·메일/DM 전송·삭제.
  여기 닿으면 **실행 직전에 멈추고 물어본다.** **"조회만" 이 기본값이다.**
- **확인과 클릭을 같은 실행에 넣지 마라.** 확인 → (출력을 사람이 읽는다) → **그 다음 실행에서** 클릭.
- **목록 대량 수집 금지.** 필요하면 공식 API. 스크래핑은 대부분 약관 위반이다.
- **`DOMAIN.md` 를 손대지 마라.** 심부름이 도메인에 남기는 건 `notes.md` 한 줄뿐이다.

| 두 번째 하는 반복 절차 | `site_map.json` 그 사이트의 `recipes` |

뭘 적었는지 사용자에게 한 줄로 보여줘라.

## 비밀 취급

- `*.local.*` 파일의 **내용을 절대 출력하지 마라.** 존재 여부까지만.
- 자격증명은 `module_browser._login` 밖으로 안 나온다. 값을 argv·로그·요약에 싣지 마라.
- **스크린샷엔 개인정보가 찍힌다** — 커밋·공유 금지(`.gitignore` 가 `*.png` 를 막는다).
- `domains/` 안의 내용을 커밋되는 파일(`site_map.json`·`LESSONS.md`)에 옮겨 적지 마라.
