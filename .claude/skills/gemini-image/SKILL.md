# /gemini-image — 그림을 뽑아 온다

> `/gemini-image <무엇을 몇 장, 어디에>` 가 기본이다.
> 예: `/gemini-image 픽셀 로딩화면 배경이랑 캐릭터 4명, out/art 폴더에`
>
> 이 스킬은 **`/errand` 의 특수한 경우**다 — 크롬을 몰고 가서 «보고 오는» 대신 «만들어 온다».
> 브라우저 공통 함정은 [`LESSONS.md`](../../../LESSONS.md) §브라우저, 여기엔 **제미나이 이미지 생성에만 해당하는 것**을 담는다.

---

## 한 줄로

```powershell
python .claude/skills/gemini-image/gen.py --out <폴더> --jobs <jobs.json> [--ref <화풍기준.png>]
```

`jobs.json` — 이름과 프롬프트의 배열. 이름이 곧 파일명(`<이름>.png`)이다:
```json
[{"name": "loading_bg", "prompt": "Pixel art, 16-bit ... Vertical 9:16 ... no text, no UI."},
 {"name": "mascot",     "prompt": "Same style ... flat solid magenta background #FF00FF ..."}]
```

| 옵션 | 뭐냐 |
|---|---|
| `--ref <png>` | 🔴 **화풍 고정.** 대화 시작 때 첨부하고 프롬프트 앞에 "이게 화풍 기준"을 붙인다 |
| `--per-chat N` | N장마다 **대화를 새로 연다** (기본 5). 안 그러면 렌더러가 죽는다 |
| `--wait N` | 한 장 기다리는 상한 초 (기본 200). 실측 **31~69초** |
| `--port` | 크롬 디버그 포트. 기본 9222 |
| `--pause A-B` | 장마다 보내기 전 A~B초 무작위로 쉰다(기본 `8-25`, 받기 전엔 2~6초) |
| `--skip-done` | `<이름>.png` 가 있으면 건너뛴다(끊긴 배치 이어 돌리기) |
| `--canvas` | 옛 방식(미리보기 1024px 를 캔버스로 뜸). **기본은 «원본 크기 이미지 다운로드» 버튼을 누른다** |
| `--reuse-tab` | 새 탭을 열지 않고 있던 제미나이 탭을 쓴다. **기본은 «자기 탭을 새로 연다»** |

그림을 보여주고 **글로 답을 받고** 싶으면 짝 스크립트:
```powershell
python .claude/skills/gemini-image/ask.py --images a.png b.png --prompt "이 화면 뭘 고칠까" [--out 답.md]
```

## 절차

1. **크롬이 떠 있나** — `python -m module_browser status`. 없으면 `python -m module_browser launch`.
2. **로그인 확인** — 제미나이 입력칸(`div[contenteditable=true]`)이 있으면 로그인된 것이다. 없으면 사람이 그 크롬 창에서 직접 로그인한다.
3. **첫 한 장을 «화풍 기준»으로 뽑는다.** 이게 제일 중요하다 — 이후 전부 여기에 맞춘다.
4. **눈으로 본다.** `Read` 로 PNG 를 열어 확인해라. 🔴 **파일이 생겼다고 맞는 그림이 아니다**(함정 ⑦).
5. 나머지를 `--ref` 로 뽑는다. 역시 눈으로 본다.
6. 공개할 그림이면 쓰는 곳에 **AI(제미나이)로 만든 그림이라고 적는다.**

## 프롬프트 쓰는 법 (실측으로 먹힌 것)

- **화풍·시대·팔레트를 앞에**: `Pixel art, 16-bit SNES JRPG style. Limited palette, crisp hard pixels, no anti-aliasing.`
- **비율을 말로 박아라**: `Vertical 9:16 portrait composition` / `Wide horizontal composition`.
- 🔴 **금지를 반드시 넣어라**: `no text, no letters, no UI, no watermark.` 안 넣으면 글자가 박혀 나오고, **한글은 거의 항상 깨진다.**
- 🟢 **반대로 «글자가 주제»인 레터링은 된다**: `The Korean text must read exactly "가나다라" (four Hangul syllables: 가 나 다 라), spelled correctly, nothing else written.`
  — **음절을 풀어서 한 번 더 적어라.** 붓·네온·레트로 9장 9/9 정확.
  쌍자음도 됐다(6/6) — 먹힌 조각: `the sixth syllable is 찌 … DOUBLE consonant ㅉ (two ㅈ shapes side by side). It is NOT 지`.
  ⚠️ 표본은 한 단어뿐이다. ⚠️ `no mockup` 을 넣어도 간판 사진으로 나올 때가 있다(1/9).
- 🔴 **투명 배경이 필요하면 «마젠타»로 시켜라**: `completely flat solid magenta background, exact color #FF00FF, no shadows, no gradient.`
  제미나이는 알파 PNG 를 안 준다 — 받아서 키잉으로 뚫는다: `r>150 and b>150 and g<110 and (r+b)/2-g>80 → (0,0,0,0)`.
  실측: 인물 시트 62% · 아이콘 시트 90% 가 깨끗하게 뚫렸다.
- **바꾸고 싶은 것만 말하고 나머지는 "Same style"**: 레퍼런스가 붙어 있으니 화풍은 다시 안 적어도 된다.
- ⚠️ **레퍼런스와 «다른 장면»이라고 못박아라** — `Draw a NEW scene:` 을 안 붙였더니 레퍼런스를 거의 그대로 다시 그렸다.

## 🔴 함정 — 전부 실측이다

| # | 함정 | 대응 |
|---|---|---|
| ① | 사이드바 **「새 채팅」 클릭이 조용히 씹힌다** | **주소로 가라** — `https://gemini.google.com/app` |
| ② | 한 탭에 큰 이미지가 **~10장 쌓이면 렌더러가 죽는다** | **N장마다 대화를 새로 연다**(`--per-chat`) |
| ③ | 생성물을 `fetch(blob:)` 로 받으면 **"Failed to fetch"** | canvas 에 `drawImage` → `toDataURL` |
| ④ | 전송 클릭이 **성공 보고하고도 안 보내진다** | 클릭 성공이 아니라 **입력칸이 비었는지**로 판정하고 재시도 |
| ⑤ | 텍스트로 "같은 스타일 유지"는 **안 먹는다** | 레퍼런스 PNG 를 **첨부**한다 |
| ⑥ | **마지막 탭**을 닫으면 크롬이 통째로 종료된다 | 내 탭만, 다른 탭이 남아 있을 때만 닫는다 |
| ⑦ | 🔴 **보내는 순간 첨부한 레퍼런스가 대화에 되비친다** — 그걸 집으면 3초 만에 «성공»하고 레퍼런스가 저장된다 | 보낸 뒤 **10초 지나고** 목록을 다시 떠서 새로 뜬 것만 본다 |
| ⑧ | 🔴 **앞 그림이 그려지는 중이면 보내기 버튼이 죽어 있다** | 중지 버튼이 사라질 때까지 기다린 뒤 보낸다(`idle()`) |
| ⑨ | `until` 에 요소를 돌려주는 JS 를 주면 `Object reference chain is too long` | `!!document.querySelector(...)` 로 불리언을 돌려라 |
| ⑩ | 🔴 **「업로드 및 도구」(+) 메뉴가 합성 클릭에 안 열린다** → 파일 input 이 영영 안 생긴다 | **붙여넣기로 우회**(`paste_attach()`). 레퍼런스는 **1100px 이하**로 줄여서 줘라 |
| ⑪ | 🔴🔴 **탭이 «배경»이면 전송이 조용히 씹힌다** | **`Page.bringToFront`** 한 줄. 재시도를 늘리지 마라 |
| ⑫ | 🔴 **같은 대화에서 이어 뽑으면 앞 그림이 다음 그림에 «섞인다»** | 서로 독립인 시트는 **`--per-chat 1`**. 화풍은 `--ref` 가 고정한다 |
| ⑬ | ⚠️ **자모 단독은 음절로 바로잡혀 나온다** — ㅛ→「요」, ㅇ→숫자 0 | 틀릴 모양을 이름 불러 금지: `NOT the syllable 요`, `ROUND ring, NOT a tall zero` |
| ⑭ | 🔴 **여러 세션이 한 크롬을 같이 쓴다** — 있던 제미나이 탭을 집으면 남의 대화에 끼어든다 | 기본이 **새 탭을 열어 그 id 로만** 붙는다 |
| ⑮ | ⚠️ 장과 장을 똑같은 간격으로 두드리면 봇처럼 보인다 | 보내기 전 무작위 대기(`--pause`) · 받기 전 2~6초 |
| ⑯ | 🔴 **받기 전 쉬는 사이 미리보기가 큰 그림으로 갈아 끼워진다** → `저장 실패` | 받기 직전에 새로 뜬 것 중 마지막을 다시 잡는다(코드에 박힘). 끊긴 배치는 `--skip-done` |
| ⑰ | ⚠️ **«이미지 안 나옴»이 연속으로 났다** — 세 번째엔 사람이 그 탭에서 그림을 직접 봤다 → **생성이 아니라 «감지» 실패** | 또 나면 `--reuse-tab` 으로 탭을 남기고 화면부터 찍는다. 급하면 `/chatgpt-image` 로 돌린다 |
| ⑱ | 🔴 **캔버스로 뜬 건 «미리보기»다 — 1024×853. «원본 크기 이미지 다운로드»를 누르면 2266×1888** | 기본이 버튼 누르기. 못 받으면 캔버스로 대신 받고 «해상도 낮음»을 찍는다 |
| ⑲ | 🔴 **ChatGPT 와 동시에 돌리면 원본 다운로드가 ChatGPT 폴더로 샌다** — 다운로드 경로가 크롬 전체 설정이라서 | 해상도가 중요하면 둘을 차례로 돌린다 |

## 절대 안 하는 것

- **대량 생성 금지.** 한 번에 수십 장씩 돌리지 마라 — 계정이 걸리는 게 그림 못 받는 것보다 훨씬 비싸다.
- **남의 탭·신청서·결제 화면을 건드리지 마라.**
- **사람 얼굴 사진·실존 인물을 넣어 만들지 마라.**
- ⚠️ **저작권**: 생성물의 상업적 사용 조건은 구글 약관을 따른다. 판매·배포할 거면 **사람이 확인하고 결정한다.**
- **사람 흉내 동작**(마우스 흔들기 등 자동화를 «숨기는» 장치)은 넣지 않는다. 무작위 대기는 속도 조절이지 위장이 아니다.
