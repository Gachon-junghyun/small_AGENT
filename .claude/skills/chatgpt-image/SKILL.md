# /chatgpt-image — ChatGPT 로 그림을 뽑아 온다

> **`/gemini-image` 의 ChatGPT 판.** 사용법·`jobs.json` 형식·절차가 같고, 사이트 조작만 다르다.
> 프롬프트 쓰는 법·절대 안 하는 것 → [`../gemini-image/SKILL.md`](../gemini-image/SKILL.md) 를 그대로 따른다.

⚠️ **계정 위험을 알고 쓴다.** ChatGPT 는 자동화에 민감하다 — 사람이 직접 시킨 것만 대행하고,
**대량 생성 금지**가 제미나이보다 더 무겁다. 계정이 걸리면 그림 몇 장보다 훨씬 비싸다.

---

## 한 줄로

```powershell
python .claude/skills/chatgpt-image/gen.py --out <폴더> --jobs <jobs.json> [--ref <화풍기준.png>]
```

| 옵션 | 뭐냐 |
|---|---|
| `--ref <png>` | 화풍 고정. 대화를 새로 열 때마다 첨부하고 프롬프트 앞에 "이게 화풍 기준"을 붙인다 |
| `--per-chat N` | N장마다 대화를 새로 연다 (기본 3). 서로 독립인 시트면 `1` |
| `--wait N` | 한 장 기다리는 상한 초 (기본 240). 실측 **27~48초** |
| `--pause A-B` | 장마다 보내기 전 A~B초 무작위로 쉰다(기본 `8-25`). 받기 전엔 2~6초 |
| `--skip-done` | `<이름>.png` 가 있으면 건너뛴다(끊긴 배치 이어 돌리기) |
| `--port` | 기본 9222 |
| jobs 의 `"ref"` | **장마다 다른 첨부**(예: 렌더·사진을 한 장씩 다듬기). 있으면 `--ref` 대신 그걸 붙이고 «화풍 기준» 문구를 안 붙인다 — 쓰임새는 프롬프트에 적어라. `--per-chat 1` 과 같이 써라 |
| `--canvas` | 옛 방식(미리보기를 캔버스로 뜸). **기본은 그림을 눌러 뷰어의 `다운로드` 버튼으로 받는다** |

**늘 자기 탭을 새로 열어** 그 탭만 쓰고, 끝나면(도중에 죽어도) 그 탭만 닫는다. 사람이 쓰던 ChatGPT 탭은 안 건드린다.
쉬는 법과 로그는 `gemini-image/gen.py` 에서 import 한다 — 그 파일을 지우면 이 스크립트도 죽는다.

## 절차

1. `python -m module_browser fast tabs` 로 크롬이 떠 있나 본다. 로그인은 사람 몫이다.
2. 첫 한 장을 화풍 기준으로 뽑고 **`Read` 로 눈으로 본다**. 파일이 생겼다고 맞는 그림은 아니다.
3. 나머지를 `--ref` 로 뽑는다. 역시 눈으로 본다.

## 🔴 실측

| # | 사실 | 대응(`gen.py` 에 박힘) |
|---|---|---|
| ① | 입력칸이 **ProseMirror**(`#prompt-textarea`)다. `innerText=` 로 박으면 에디터 상태와 어긋난다 | 포커스 → 비우기 → **`Input.insertText`** |
| ② | **보내기 버튼은 글자를 쳐야 생긴다**(`aria-label="보내기"`). 생성 중엔 `aria-label="중지"` | 판정은 클릭 성공이 아니라 **입력칸이 비었나** |
| ③ | 🔴 **중지 버튼이 그림보다 «먼저» 사라진다** — 24초에 중지가 없어지고 27초에 그림이 떴다 | 중지 버튼으로 끝을 판정하지 않는다. **새 `생성된 이미지` 의 src 가 두 번 연속 같고 중지가 없을 때** 받는다 |
| ④ | 결과는 `alt="생성된 이미지 N"` 인 `blob:` img | canvas 로도 원본 해상도 그대로 받힌다. 레퍼런스 되비침은 alt 가 달라 안 걸린다 |
| ⑤ | `input[type=file][accept="image/*"]` 가 **처음부터 DOM 에 있다** | `DOM.setFileInputFiles` 한 방 |
| ⑥ | 버튼에 `data-testid` 가 거의 없다 | `aria-label` 로 잡고, `data-testid` 는 예비로만 |
| ⑦ | 🔴 **`--ref` 첨부가 «두 번째 대화»에서 조용히 빠졌다** → ChatGPT 가 «참고 이미지를 다시 올려 달라»고 되물었고 240초 뒤 `이미지 안 나옴`. **타임아웃이 아니었다** (두 번 밟음) | `attach()` 가 `«파일명» 제거` 버튼과 `data:` 미리보기(업로드 끝)를 확인하고, 안 붙으면 세 번까지 다시 넣고, 보내기 직전에 한 번 더 본다. 그래도 없으면 **레퍼런스 없이 보내지 않고 실패**로 둔다 |
| ⑧ | 🟢 **«눌러서 받기»가 기본이다** — 미리보기 버튼(`generated-image-preview`) → 뷰어 `다운로드`. 받은 파일 이름은 ChatGPT 가 붙인 제목이라 `<이름>.png` 로 바꾼다 | ChatGPT 는 받은 파일도 캔버스와 같은 해상도였다 — 화질 차이가 아니라 «원본 파일 그대로»의 차이다(제미나이는 다르다) |
| ⑨ | 🔴 **«어느 이미지가 더 마음에 드세요?» 두 장 비교가 뜨면 다운로드 길에서 멈췄다** | 고르는 건 사람 몫이라 누르지 않고 **두 장 다 받는다** → `<이름>_a.png`·`<이름>_b.png`. ⚠️ 그 화면엔 앞 대화 그림까지 섞인다 — 손으로 받을 땐 새로 뜬 것 중 마지막 둘만 |
| ⑩ | 🔴 **렌더·사진 «다듬기»(jobs `"ref"`)는 «빼기»도 «지어 넣기»도 한다** — «벽 그림 그대로»를 목록 한 단어로만 적었더니 벽 그림이 통째로 빠졌고, 한 프롬프트를 모든 컷에 썼더니 간판이 안 보이는 컷에 간판을 지어 넣었다 | **지킬 물건은 따로 한 문장**(«같은 자리·같은 크기·같은 내용, 지우거나 비우지 마라»). **컷마다 그 컷에 보이는 것만** 적고, 안 보이는 컷엔 «이 화면엔 간판·글자가 없다, 넣지 마라». 받은 뒤 원본과 나란히 대조 |

⚠️ **ChatGPT 가 그림 대신 되물을 때가 있다.** 그러면 `이미지 안 나옴 — 되묻는 답이었을 수 있다` 로 실패 처리된다.
**실패하면 그 대화를 열어 답부터 봐라** — 그 장만 다시 돌리면 되는 경우가 많다. 프롬프트 첫머리에 `Create an image:` 를 박아라.
