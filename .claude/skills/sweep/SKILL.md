# /sweep — 전부 훑고, 걸린 것만 올린다

> `/sweep 아침` · `/sweep 저녁` · 인자 없으면 **12시 이전=아침**.
> `/sweep 저녁 도메인=study` → 그 도메인 하나만. `/sweep 제외=study` → 그 도메인을 건너뛴다.

**도메인이란** `domains/<이름>/` 폴더 하나 + 그 안의 `DOMAIN.md` 한 장이다(틀은 [`_TEMPLATE/DOMAIN.md`](../../../_TEMPLATE/DOMAIN.md)).
학업·취업·주식·가게 일처럼 «매일 챙겨야 하는 삶의 한 갈래»마다 하나. 스키마 없는 사람 말이다.

**이 스킬은 모든 도메인에 하나뿐이다.** 도메인이 4개든 15개든 이 파일은 안 는다.
도메인별 스윕·파서·서브에이전트 «정의»를 만들지 마라. 부족하면 이 파일을 고쳐라.

---

## 0. 사람이 안 보고 있다는 걸 잊지 마라 — 이게 이 스킬의 제일 중요한 절이다

예약 작업으로 돌면 사람이 안 보는데 셸과 크롬을 쥐고 있다. 그래서 아래를 스킬이 지킨다.

| 금지 | 왜 |
|---|---|
| **되돌릴 수 없는 것 일절 금지** — 제출·신청·결제·주문·발행·전송·삭제 | 취소할 사람이 없다. 발견하면 **"사람이 해야 함"으로 올리고 끝** |
| **확인과 클릭을 같은 실행에 넣기** | 한 번에 하면 그건 확인이 아니라 기록일 뿐이다 |
| **확인 못 한 값 채우기** | "확인 못 함"으로 남긴다. 조용히 틀리면 못 잡는다 |
| **남의 도메인에 쓰기·개인정보 기록** | 소유자가 내가 아니면 조회만. 이름·연락처 대신 **수치로만** |
| **캡차·429·로그인 벽 뚫기** | 후퇴 신호다. 재시도 금지 → [`errand/SKILL.md`](../errand/SKILL.md) §후퇴 신호 |
| **`*.local.*` 내용 출력** | 존재 여부까지만 |

## 1. 도메인을 전부 읽는다

`domains/*/DOMAIN.md` 를 전부 읽고 **세 칸만** 뽑는다:
`매일 뭘 봐야 하나`(=할 일) · `뭘 알려줘야 하나`(=올릴 조건) · `하지 말 것`(=최우선 제약).
`notes.md` 는 **이미 아는 것**이다 — 다시 조사하지 말고 **바뀌었는지만** 본다.

`매일 뭘 봐야 하나` 가 `없음` 이면 그 도메인은 건너뛴다. 할 일을 **발명하지 마라.**
`domains/` 가 비어 있으면 "도메인이 없다 — `_TEMPLATE/DOMAIN.md` 를 복사해 하나 만들어라"로 끝낸다.

## 2. 도메인마다 실제로 수행한다 — 도메인 하나 = 자식 하나

`Agent` 가 있으면 도메인마다 서브에이전트를 하나씩 띄운다. 없으면 순차로 한다. 둘 다 정상 경로다.

| 답이 어디 있나 | 뭘 쓰나 |
|---|---|
| 도메인 폴더 안(원장·날짜·첨부) | 그냥 읽는다. **제일 싸다** |
| 공개 웹 | `WebSearch` / `WebFetch` |
| 로그인 벽 뒤 · 지도에 있는 사이트 | **`/errand <도메인> <물음>`** |
| 못 하겠다 | **"확인 못 함" + 왜** |

### 2-0. 🔴 출처 없는 줄은 올리지 마라

| 올릴 때 반드시 붙는 것 | 예 |
|---|---|
| **어디서 봤나** | 열어본 URL, 또는 「`notes.md` 8월 16일 줄」 |
| **언제 봤나** | 방금 본 것인지 **어제 적어둔 것인지** |
| **직접 열었나** | `크롬` / `WebFetch` / `원장만` 셋 중 하나 |

- 🔴 **「원장에 적혀 있다」와 「지금 가서 봤다」를 같은 줄에 섞지 마라.** 어제 실측을 오늘 실측인 양 올리면 조용히 틀린 값이다.
- 🔴 **마감이 D-1 이내인 건은 «반드시» 크롬으로 직접 열어라.** WebFetch 요약은 마감 시각·자격·정원 같은 세부를 조용히 뺀다.

### 2-1. 자식에게 넘기는 법 — 통째로 넘기지 마라

자식은 이 파일을 **안 읽고** 뜬다. 그러니 프롬프트에 반드시 넷을 넣는다:

1. **§0 표 전문** — 요약하지 마라. 빠뜨리면 자식이 버튼을 누른다.
2. 그 도메인의 **세 칸** — `매일 뭘 봐야 하나` · `뭘 알려줘야 하나` · `하지 말 것`
3. **범위**: `domains/<그 도메인>/` 안에서만 쓴다. **남의 도메인 폴더를 열지 마라.**
4. **돌려줄 형식**: `걸린 것` / `확인한 것` / `확인 못 함` 셋. 최종 보고는 부모가 조립한다.

### 2-2. 크롬은 «포트당» 한 대다

같은 포트를 자식 둘이 동시에 물면 서로 탭을 뺏는다. **크롬이 필요한 도메인은 병렬로 띄우지 마라** —
나머지를 먼저 병렬로 돌리고, 크롬 쓸 자식은 하나씩. (포트가 다르면 브라우저가 달라서 안 부딪힌다.)

### 2-3. 어느 경로든

- **한 도메인에서 막혔다고(자식이 죽었다고) 나머지를 건너뛰지 마라.** 그 도메인만 "확인 못 함"으로 적고 다음으로.
- **자식이 돌려준 걸 그대로 믿지 마라.** 「확인 못 함」이라고 왔으면 그대로 올려라 — 부모가 그럴듯하게 메우지 마라.

## 3. 판정 — `뭘 알려줘야 하나` 에 걸리나

**걸린 것만 올린다.** 안 걸린 도메인은 보고에 한 줄도 쓰지 마라.

| | 초점 |
|---|---|
| 🌅 아침 | **오늘 사람이 움직여야 할 것.** 마감 D-n, 오늘 자 공지, 오늘 답해야 할 연락 |
| 🌙 저녁 | **오늘 바뀐 것 + 내일 준비.** 아침 이후 새로 뜬 것, 내일이 마감인 것 |

### 원장끼리 대조해라 — 스윕만 할 수 있는 일이다 (부모가 한다)

전부 읽는 건 부모뿐이다. 판정 전에 **같은 사실을 두 도메인이 다르게 적고 있지 않은지** 보고, 어긋나면 **제일 위에 올려라.**
- 실제로 당했다: 한 도메인은 "복학 신청 D-3"을 매일 올렸는데, 다른 도메인엔 포털 실측으로 **이미 복학했다**고 적혀 있었다.
- **어느 쪽이 맞는지 네가 정하지 마라.** 근거의 출처를 나란히 적어 사람에게 넘겨라.
- **날짜가 겹치는 것**도 본다. 도메인이 달라도 같은 날 같은 시간이면 충돌이다.
- **틀린 경고는 안 뜨는 경고보다 나쁘다.** 한 번 "저거 또 틀렸네"가 되면 진짜 마감도 흘려본다.

## 4. 기록 — 같은 턴에

| 무엇 | 어디에 |
|---|---|
| 도메인 사실 | `domains/<도메인>/notes.md` 에 **한 줄** (`YYYY-MM-DD`, 끝난 건 `[x]` 로 남기고 지우지 않는다) |
| 이번 보고 전문 | **`domains/SWEEP.md`** 를 덮어쓴다 (아래 §5 형식) |
| 돌았다는 흔적 | **`domains/SWEEP_LOG.md`** 맨 아래에 한 줄: `YYYY-MM-DD HH:MM · 아침/저녁 · 도메인 N · 걸린 것 M` |
| 사이트 함정·셀렉터 | [`LESSONS.md`](../../../LESSONS.md) §브라우저 · URL·`access` 는 `site_map.json` |

- 새로 알아낸 게 없으면 `notes.md` 에 **아무것도 쓰지 마라** — "오늘도 변화 없음"이 쌓이면 원장이 못 쓰게 된다.
- `SWEEP_LOG.md` 는 올릴 게 없어도 쓴다 — **"안 돌았다"를 알 수 있는 유일한 곳**이다.
- 마지막 답변에 **「SWEEP.md 를 썼다」를 한 줄** 적어라. 안 적혀 있으면 안 쓴 것이다.

## 5. 보고 — 짧을수록 좋다

```
🌅 스윕 2026-10-18 07:12 · 도메인 4 · 걸린 것 2

⚠ 사람이 해야 함
- career: 장학 신청 마감 10/21 (D-3) — 제출은 사람이 (포털 로그인 필요) · 크롬 · 방금 봄

▸ 확인한 것
- study: 10/24 과제 마감 그대로. 새 공지 없음 · 크롬 · 방금 봄

· 확인 못 함
- stock: 증권사 로그인이 풀려 있음 → 사람이 다시 로그인해야 함
```

**아무것도 안 걸리면 한 줄로 끝내라** — `🌅 스윕 07:12 · 도메인 4 · 걸린 것 없음`.
매번 긴 보고를 쓰면 며칠 만에 안 읽게 되고, **한 번 안 읽기 시작하면 진짜 마감이 떠도 안 읽는다.**

## 자동으로 돌리고 싶으면

Claude Code 의 예약 작업(`/schedule`, 또는 데스크톱 앱의 Scheduled Tasks)에 **"/sweep 아침 을 불러라"** 한 줄만 건다.
절차를 그쪽에 복사하지 마라 — 두 벌이 되어 어긋난다. **PC 가 자면 그날 스윕은 안 돈다** — 그래서 `SWEEP_LOG.md` 를 본다.

## 하지 말 것

- **`DOMAIN.md` 를 고치지 마라.** 저건 에이전트가 따르는 지시문이라, 스스로 고치면 자기 지시를 자기가 바꾸는 게 된다. 고칠 게 보이면 사람에게 올려라.
- `domains/` 안의 내용을 커밋되는 파일(`LESSONS.md`·`site_map.json`)에 옮겨 적지 마라.
- 🔴 **출처 없는 줄을 올리지 마라. D-1 이내인데 크롬을 안 열었으면 그건 아직 확인한 게 아니다.**
- **자식에게 원장 대조(§3)를 시키지 마라.** 자식은 남의 원장을 못 본다 — 대조는 부모만 할 수 있다.
